# Add a habit

Help the user turn a wish ("I want to be healthier") into one daily habit they
can tick off on the Habit Tracker page.

1. Ask what they want to change, if they have not said.
2. Suggest up to three small habits. Each one must:
   - take ten minutes or less;
   - be done once a day;
   - start with a verb, for example "Walk for 10 minutes".
3. Let the user pick one, or change the words.
4. Give the final habit as one short line in quotes, under 40 characters.
5. Tell the user to open **Habit Tracker** in the sidebar, paste the line into
   the box and press **Add**.

Do not suggest more than one new habit at a time. Small and steady beats big.
