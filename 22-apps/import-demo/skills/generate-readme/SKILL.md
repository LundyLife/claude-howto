# Generate a README

Read the project first: its package file, main entry point and tests.

Write these sections, in order:

1. What the project is, in two sentences.
2. How to install it.
3. How to use it, with one copy-paste example.
4. How to run the tests.
5. How to contribute.
6. The license.

Show the user the draft before you replace an existing README.
