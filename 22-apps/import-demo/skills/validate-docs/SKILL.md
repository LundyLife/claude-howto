# Validate docs

Read only. Report, do not fix, unless the user asks.

1. Check every link in the docs folder. List broken ones.
2. Check that each public function or endpoint has docs.
3. Run the code examples where it is safe to do so. List the ones that fail.
4. Report problems as a list with the file and line.
