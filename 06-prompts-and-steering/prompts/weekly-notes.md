# Weekly notes summary

Read every note in `~/my-project/notes/` that changed in the last seven days.

Then write a summary with exactly five bullets:

1. The most important thing that happened.
2. One thing that is finished.
3. One thing that is still open.
4. One thing I said I would do next.
5. Anything I should not forget.

Keep each bullet to one short sentence. After the bullets, list the note files
you read. Do not change any files.

If the `notes` folder is missing or empty, say so and stop.
