# API documentation generator

Write documentation for the API in this project.

1. Find the files that define the API endpoints. If you cannot find them, ask me where they are.
2. Read each endpoint's function signature and any comments above it.
3. Group the endpoints by module or by URL path.
4. For each endpoint, describe the request, the response and the possible errors.
5. Add one `curl` example for each endpoint.

Write the result to `docs/api.md`. Show me the plan before you write the file.
