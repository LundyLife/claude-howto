## Learning tips

- Do the exercises, not just the reading. Each module's **Try it yourself**
  section is where it sticks.
- Keep one practice folder (`~/my-project`) for every exercise.
- Use the [glossary](GLOSSARY.md) whenever a word is new.
- Quiz yourself after each module with the lesson-quiz skill
  ([how](README.md#running-the-built-in-quiz)).
