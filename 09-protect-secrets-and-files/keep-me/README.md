# keep-me

This is a practice folder for
[Module 9: Protect your secrets and your files](../README.md).

Copy it into your practice project (`~/my-project/keep-me/`), save it in git,
and then let the agent delete it on purpose. You will get it back with git.

Nothing in here matters. It is safe to lose.

## A line to check

If you can read the line below after you restore the folder, the restore
worked:

```text
keep-me is back. Git remembered it.
```
