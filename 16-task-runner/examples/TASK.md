# Task: Start a reading-list folder

This is a practice task for the Kiro Crew task runner. It has three small steps.
Run it in your practice folder, for example `~/my-project`.

## Steps

1. Create a folder named `reading-list` in the current folder.
2. Inside `reading-list`, write a file named `README.md`. Its first line is the
   heading `# Reading list`. Below it, write two short sentences that say this
   folder holds books to read and notes about them.
3. Inside `reading-list`, write a file named `test-list.md`. It is a checklist
   of exactly three checks a person can do by hand to confirm the folder is
   right. Use this format, one check per line:
   - `- [ ] The reading-list folder exists.`
   - `- [ ] README.md starts with the heading "# Reading list".`
   - `- [ ] test-list.md has exactly three checks.`

## Done when

- The folder `reading-list` exists.
- `reading-list/README.md` starts with `# Reading list` and has two sentences.
- `reading-list/test-list.md` has exactly three lines that start with `- [ ]`.
