# Task: Start a packing list

This is a starter task for "Try it yourself" in Module 16. It has two small
steps. Run it in your practice folder, for example `~/my-project`.

Change the steps to suit you before you run it.

## Steps

1. Create a folder named `trip-notes` in the current folder.
2. Inside `trip-notes`, write a file named `packing.md`. Its first line is the
   heading `# Packing list`. Below it, write a checklist of five things to pack
   for a weekend away, one per line, each starting with `- [ ]`.

## Done when

- The folder `trip-notes` exists.
- `trip-notes/packing.md` starts with `# Packing list`.
- `trip-notes/packing.md` has exactly five lines that start with `- [ ]`.
