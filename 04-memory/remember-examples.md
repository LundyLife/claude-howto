# Lines that make the agent remember you

Copy any line below into a dashboard chat (**Surface: Dashboard**). Start it
with `Remember:` so the agent saves it as a lesson. Change the words to fit you.

A good lesson is one short sentence. It says what to do and, if it matters,
when. Save only rules you want in every future chat.

## How you like answers

```text
Remember: always answer me in bullet points.
```

```text
Remember: keep answers under 150 words unless I ask for more.
```

```text
Remember: when you explain something, give one small example first.
```

```text
Remember: end long answers with a two-line summary.
```

## Units, dates and language

```text
Remember: always give me measurements in centimeters and kilograms.
```

```text
Remember: write dates as YYYY-MM-DD.
```

```text
Remember: use British spelling.
```

## How you like to work

```text
Remember: ask me before you delete any file.
```

```text
Remember: when you change a file, tell me which lines you changed.
```

```text
Remember: when I ask for a plan, give me numbered steps I can tick off.
```

## Correcting it

You can also save a lesson by correcting the agent. Say what was wrong and what
to do instead:

```text
That was too long. Remember: give me the short version first, then ask if I want more.
```

```text
No, I use a Mac, not Windows. Remember that I use macOS.
```

## What not to save

Lessons are for rules that last. Do not save:

- Passwords, keys or other secrets. Module 9 shows the safe place for those.
- Facts that change every day, such as today's to-do list.
- Rules for one project only. A steering file for that project is a better
  place. Module 6 shows how.

To keep a chat from saving anything, open it in **Incognito** or **Temporary**
mode. See [the memory module](README.md#4-lesson-43-private-chats).
