# Module recommendations

Use these when a module is a gap. Links are relative to this file
(`.kiro/skills/self-assessment/references/`). Times come from
`LEARNING-ROADMAP.md`. Each line is taken from the module's own
**What you will learn**, **Try it yourself** and **Check your work**
sections; if a module changes, update it here.

## Module 0: What is an AI agent? (about 15 min)

**Score 0 (learn):**

- Module: [00-what-is-an-agent](../../../../00-what-is-an-agent/README.md)
- Focus on: what a **prompt** is, and how a clear prompt helps; what a **model** is, and why it is not a search engine; what a **tool call** is, and how to spot one in a chat
- Key exercise (**Try it yourself**): write three prompts for one task: vague, clear, and clear with an example
- Done when: you can say in one sentence what a tool call is

**Score 1 (review):**

- Focus on: why an answer can be wrong, even when it sounds sure; why a good agent asks you before it acts
- Check yourself: run the lesson-quiz skill on Module 0
